# JR Primary — Laporan Perkembangan Agama Islam

Paket ini berisi rancangan website responsif untuk orang tua dan starter penghubung Google Apps Script.

## Isi folder
- `index.html` — struktur halaman
- `styles.css` — desain responsif biru, siap menerima logo sekolah
- `app.js` — interaksi dan contoh laporan fiktif
- `Code.gs` — starter backend Google Apps Script
- `PANDUAN.md` — panduan pemasangan

## Pratinjau
Buka `index.html` di browser. Klik **Lihat contoh laporan** untuk mencoba tampilan. Data contoh adalah data fiktif dan belum mengambil data dari workbook sekolah.

## Penting tentang privasi
Jangan mengunggah spreadsheet berisi nama lengkap, NISN, progress, atau informasi anak ke repositori GitHub publik. Jangan pernah menaruh nama lengkap dan NISN atau seluruh data siswa di `app.js`. Website ini masih mode pratinjau sampai backend dipasang dan diuji. Versi ini mencari laporan menggunakan nama lengkap saja sesuai permintaan. Nama bukan verifikasi identitas; sebelum publikasi, batasi data yang ditampilkan dan minta persetujuan sekolah.
